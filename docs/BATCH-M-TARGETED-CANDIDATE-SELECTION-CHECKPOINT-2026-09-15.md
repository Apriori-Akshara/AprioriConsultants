## 3. Controlled-selection rules implemented

Content replacement:

- `CONTENT_REPLACEMENT`
- `CONTENT_REPLACEMENT_PLUS_DIFFICULTY_CALIBRATION`

These may receive deterministic eligible candidate selections for downstream approval.

Difficulty-only:

- `DIFFICULTY_CALIBRATION_AND_POSSIBLE_REPLACEMENT`

These receive candidate options for review but do not receive an automatic replacement selection. The report disposition is `CALIBRATION_FIRST_NO_REPLACEMENT_SELECTED`.

No candidate is treated as production-approved merely because it passes the candidate-pool quality gate.
